# Hebrew terms review (RFQ, Hebrew edition)

Checked against Israeli trade pages found with generic searches (no project data used). Verdicts: kept = found in use as written; changed = replaced by a sourced term; unverified = no trade usage found either way, left as is.
Brand and product-line names (Blum, Hettich, Caesarstone, Dekton, Fenix, LeMans, Magic Corner) stay in Latin letters. Blum Israel and Caesarstone Israel publish no Hebrew product text that could be used (blum.com/il is English only; caesarstone.co.il shows colour names in English only), so importer and kitchen-maker pages were used.
